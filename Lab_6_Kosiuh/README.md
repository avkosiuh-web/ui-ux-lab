## Підсумкові показники usability-тестування FocusPulse
- **Загальна успішність виконання завдань (Completion Rate):** `88.9%` (8 із 9 спроб виконано самостійно без підказок).
- **Середній час на виконання сценарію (Time on Task):** `24.07 с` (Сценарій 1 — `19.8 с`, Сценарій 2 — `36.9 с`, Сценарій 3 — `15.5 с`).
- **Середній бал System Usability Scale (SUS):** `84.17 балів` (рейтинг **Grade A / Excellent**, вище індустріального еталона `68.0`; 95% довірчий інтервал Стьюдента: `[65.17; 100.0]`).
