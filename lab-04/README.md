## Зміст артефактів (тека `lab-04/`)

У цій теці розміщено низькодеталізовані макети (Lo-Fi Wireframes) та схеми компонування інтерфейсу для застосунку **FocusPulse**:

1. `fig1_dashboard.svg` — Головний екран (Timer Dashboard) з накладеною 12-колонковою сіткою та 8pt модульною розміткою.
2. `fig2_task_list.svg` — Список завдань (Task List) із демонстрацією міжблочних відступів (16px Gutter).
3. `fig3_stats_detail.svg` — Форма додавання нового завдання (Add Task Modal Window).
4. `fig4_padding_margin.svg` — Інженерна специфікація внутрішніх та зовнішніх відступів (Padding/Margin) за 8pt Grid System.
5. `fig5_gestalt.svg` — Демонстрація застосування закону близькості Гештальта для групування елементів керування таймером.
6. `fig6_responsive.svg` — Схема адаптивного компонування: Desktop (1440px, 12 колонок) vs Mobile (390px, 1 колонка).
7. `fig7_z_pattern.svg` — Схема руху погляду користувача за Z-патерном на головному дашборді.
